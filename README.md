# Carry-Forward-Unleashed

## Install instructions

1. Go to the [latest release](https://github.com/MasterRDF/Carry-Forward-Unleashed/releases/latest) and download "Carry-Forward-Unleashed-main.zip".
2. Extract it. You will see a folder called "Carry-Forward-Unleashed-main", open it and move everything inside into your cod25 folder.
3. In game, go to Zombies -> Weapons -> Mystery Box and check the games you want the Mystery Box to give guns from (Black Ops 7, Black Ops 6, Modern Warfare III, Modern Warfare II). All four are on by default.
