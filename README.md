# Carry-Forward-Unleashed

## Install instructions

1. Go to the [latest release](https://github.com/MasterRDF/Carry-Forward-Unleashed/releases/latest) and download "Carry-Forward-Unleashed-main.zip".
2. Extract it and move everything inside (`hid.dll`, `cleanup.bat` and the `kronos` folder) into your cod25 folder. Replace files if asked.
3. **Updating from 1.4.1 or older:** run `cleanup.bat` from your cod25 folder. It deletes the old files left over from the structure change (`mw2_guns`, `kronos\mods\mwcf_box`, `kronos\mods\mwcf_categories`, `kronos\mods\mwcf_pap`, `kronos\mods\mw_zm_loadout`).
4. Open the Kronos launcher, go to the Library tab and make sure "Carry Forward Unleashed" is switched on.
5. In game, go to Zombies -> Weapons -> Mystery Box (or press Mystery Box Loadout on the Confirm Loadout screen before a match) and check the games you want the Mystery Box to give guns from (Black Ops 7, Black Ops 6, Modern Warfare III, Modern Warfare II). All four are on by default.
6. On the same screen, press **Wall Buys** to switch which game's guns every weapon wall buy sells (Black Ops 7, Black Ops 6, Modern Warfare III, Modern Warfare II). Wall prices stay the same. Black Ops 7 by default.

## Turning it off

Switch "Carry Forward Unleashed" off in the Kronos launcher's Library, then restart the game. Switching it back on works the same way.
