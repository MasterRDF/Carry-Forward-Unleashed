# CFU Core 1.7

The base of Carry Forward Unleashed; every CFU module requires it. Install notes: INSTALL.txt in the release zip. The MW weapon and operator DLLs (mw2_guns, mw2_guns_fixes, mwcf_operators) live here and always load with Core, because they also run BO6 fixes. mw2_guns keeps MWII/MWIII guns only while cfu_mw2_weapons / cfu_mw3_weapons are on. Credits for the MW operators: MW_OPERATORS_INTEGRATION.txt.
